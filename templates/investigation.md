# Investigation title

| Field | Value |
| --- | --- |
| Stage | idea / designed / attempted / completed / extended |
| Outcome | untested / supported / not-supported / inconclusive / invalidated / superseded |
| Started | YYYY-MM-DD |
| Last updated | YYYY-MM-DD |
| Authors | Name and identifier |
| Code | Link or commit |
| Data | Source, version and license |

## Question

State the uncertainty or decision this investigation was intended to resolve.

## Brief context

Explain only enough background to make the question intelligible. Link the essential prior work.

## Original hypothesis

State the expected result before describing what happened.

## Experiment or proposed test

Describe the design, controls, comparison groups, primary endpoint and stopping rule. If no experiment was performed, label this section explicitly as proposed.

## Results

Report the primary result first. Include effect sizes, uncertainty and relevant controls. Do not replace a failed primary endpoint with a favourable secondary analysis.

For an untested idea, write: `No experimental result exists.`

## Conclusion

State the narrowest conclusion justified by the result.

## What this does not show

List interpretations the evidence cannot support.

## Why this investigation stopped

State the actual boundary: hypothesis not supported, insufficient data, invalid assay, prior art, excessive cost, missing capability, or a better question.

## Reproduction and reuse

Provide commands, environment, data retrieval instructions, checksums and licenses. Identify reusable components separately from the scientific conclusion.

## Next decisive experiment

Describe the smallest experiment that would materially change the conclusion. For a closed project, say that no continuation is currently justified.

## Changes and extensions

Record corrections, independent reproductions, forks and later work without rewriting the original outcome.
