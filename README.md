# Negative Space

**Hypotheses tested, boundaries found, work preserved.**

Science is knowledge generation, not success curation.

A well-posed hypothesis does not become worthless when the expected effect is absent. An inconclusive experiment is not improved by being forgotten. A project that reaches a defensible stopping point still establishes a boundary, exposes a limitation and prevents the same uncertainty from being silently recreated by the next person.

Most scientific communication shows the narrow path that worked. Null findings, abandoned assumptions, invalid experiments and technically sound dead ends largely disappear. This distorts how science actually proceeds and leaves researchers repeating work whose outcome is already known privately.

Negative Space publishes the rest of the record. Each investigation states its question, hypothesis, methods, results, limitations and actual conclusion. Positive, negative and ambiguous findings are treated as findings. Untested ideas are labelled as ideas. Failed experiments are separated from failed hypotheses. Nothing is promoted into a stronger claim than the evidence supports.

The purpose is not to celebrate failure. It is to preserve information. Someone may avoid repeating an unproductive route, identify a better experiment, reuse the code or data, or continue from the point where an investigation stopped. That is scientific progress too.

## Entry format

Every entry contains:

1. Question
2. Brief context
3. Original hypothesis
4. Experiment or proposed test
5. Results
6. Conclusion
7. What the result does not show
8. Why the investigation stopped
9. Reproduction and reuse instructions
10. The next decisive experiment, if one is justified

Every entry also has two independent labels.

Stages: `idea`, `designed`, `attempted`, `completed`, `extended`.

Outcomes: `untested`, `supported`, `not-supported`, `inconclusive`, `invalidated`, `superseded`.

The word `failed` is not used alone because it does not identify whether the hypothesis, experiment, dataset, implementation or publication case failed.
